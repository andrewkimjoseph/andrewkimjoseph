## 🚀 About Me

I build across three areas:

**[Canvassing](https://thecanvassing.xyz)** (co-founded 2024) — a marketplace connecting African researchers with verified participants for surveys, product tests, and polls. Participants earn **GoodDollar (G$)** rewards; researchers get quality data. The ecosystem spans:
- **[Pax](https://github.com/andrewkimjoseph/pax_v2)** — Flutter participant app with ERC-4337 smart accounts, multi-token rewards (G$, cUSD, USDC, USDT), MiniPay integration
- **[Rez](https://rez.thecanvassing.xyz)** — Next.js researcher dashboard — task wizard, poll insights, Supabase analytics
- **[GoClaim](https://app.goclaim.xyz)** — autopilot daily G$ UBI claiming via ERC-4337 + BullMQ queues

**[Celina](https://usecelina.xyz)** — a Celo-native agent stack: shared SDK (`@andrewkimjoseph/celina-sdk`), local + hosted MCP server, REST API, Celeste browser wallet UI, and a Telegram bot. One tool catalog, five surfaces. Supports DeFi (Mento, Uniswap v4, Aave), governance, staking, GoodDollar UBI, and Self Agent ID humanness gating.

**Side tools** — [Days To Go](https://app.daystogo.xyz) (countdown timer SaaS), [Devi](https://github.com/andrewkimjoseph/devi) (Celo code-cracking duel for MiniPay + Farcaster), [file_mcp](https://github.com/andrewkimjoseph/file_mcp) (Dart MCP server for local file search).

Originated at **Build with Celo 7**, supported by **Prezenti** grants.

- 🔭 Shipping on **Celo mainnet** — GoodDollar, MiniPay, ERC-4337 AA
- 📱 **Flutter** (Pax) + **Next.js / TanStack Start / Vite** (Rez, Celina, Canvassing, GoClaim)
- 🤖 **AI agents on-chain** via Celina SDK + MCP + A2A protocol
