## 🚀 About Me

I co-founded **[Canvassing](https://thecanvassing.xyz)** (2024) — a marketplace connecting African researchers with verified participants for surveys, product tests, and polls. Participants earn **GoodDollar (G$)** rewards; researchers get quality data through **Rez** (dashboard) and **Pax** (mobile app).

Originated at **Build with Celo 7** and supported by **Prezenti** grants. I'm currently building **[Celina](https://usecelina.xyz)** — a Celo-native SDK + MCP stack for AI agents (DeFi, governance, UBI, wallet flows).

- 🔭 Building on **Celo mainnet** with GoodDollar, MiniPay, and ERC-4337 smart accounts
- 📱 Shipping **Flutter** mobile (Pax) and **Next.js / Vite** web (Rez, marketing, insights)
- 🤖 Exploring **AI agents on-chain** via Celina MCP + SDK
